# code-graph-go

`go install github.com/renso-ai/code-graph-go/cmd/code_graph@v1.0.0`

Thin download-on-first-run launcher for the prebuilt
`code_graph` and `code_graph-mcp` binaries. Source for the
engine lives at https://github.com/Renso-AI/code_graph
(Apache-2.0); this repo only hosts the Go launcher templates.
